# Обработка данных банковских карт и счетов

## Описание:
В данной дирректории в пакете src реализован ряд функций для работы с данными банковских карт и счетов

## Установка проекта:
Клонируйте репозиторий:
```
git clone https://github.com/LarionovSD/SkyPro
```

## Версия Python и зависимости:
Версия Python 3.13

## Примеры использования:
1. В модуле masks.py:
+ маскировка номеров банковских карт и счетов
```
def get_mask_card_number(number_card: Union[int, str])
```
*передайте данные номера карты или счета в функцию get_mask_card_number  для маскировки части номера карты или счета*

2. В модуле widget.py:
+ вывод названия карты и счет с замаскированными данными
```
def mask_account_card(number_account_card: Union[int, str])
```
*передайте данные номера карты или счета в функцию mask_account_card для вывода данных в замаскированном виде*

+ форматирование даты
```
def get_date(date_string: str)
```
*функция для форматирования строк с датами и приведения их к формату DD.MM.YYYY*

3. В модуле processing.py:
+ сортировка данных по параметру state
```
def filter_by_state(list_with_data: list, state="EXECUTED")
```
*функция filter_by_state отсортирует данные из списка словарей, по умолчанию параметр state="EXECUTED"*
+ сортировка данных по дате
```
def sort_by_date(list_with_data: list, sorting_order=True)
```
*функция для сортировка данных из списка словарей по дате, по умолчанию парамет сортировки по убыванию sorting_order=True*
