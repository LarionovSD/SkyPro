# Программа для обработки данных банковских карт и счетов

В данной дирректории в пакете src реализованы следующие функции:

в модуле masks.py:
+ маскировки номеров банковских карт и счетов

в модуле widget.py:
+ вывод названия карты и счет с замаскированными данными
+ форматирование даты

в модуле processing.py
+ сортировка данных по параметру state
+ сортировка данных по дате
